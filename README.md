# 馬太鞍溪堰塞湖土砂變遷分析

互動式網頁：以五期 1 m DEM（2025/8/16、2025/9/25、2025/10/13、2026/3/14、2026/9/14）與空拍正射影像，
分析馬太鞍溪堰塞湖潰決後（2025/9/25 → 2026/9/14）的土砂沖淤、去向與河道縱斷面變化。

**線上瀏覽：** https://kenji-liu.github.io/mataian-dam-sediment-dashboard/

## 內容

- [分析報告](docs/土砂變遷分析報告.md)：方法、結果、判讀與限制
- 區位總覽：衛星影像上的 A 崩積區、B 殘壩區、C 治理界點以上河道、D 界點下游河床
- 四個章節：殘壩區每日流失速率、各區累積土砂變化、河道縱斷面（含每公里高程表）、土砂收支
- 空間分析：沖淤分布地圖、熱力圖、雷達圖、文氏圖與變動位置圖、桑基圖、漏斗圖、樹狀圖

## 方法摘要

- 五期 DEM 重取樣至 5 m 共同網格（TWD97 / TM2，EPSG:3826），以兩期 DEM 直接相減（DoD）。
- 以分區外的穩定區（坡度 < 25°）估算並扣除各期系統偏差；沖蝕、淤積量只計 |Δz| > 1 m 的格點，淨變化不設門檻。
- 分期的值為「以 2025/9/25 為基準的累積值」逐期相減。

## 限制

- A、B、C 分區為目視劃定的近似範圍，**不是官方分區**；D 區依衛星影像上的礫石河道範圍劃定。
- 衛星影像為 2025/9/27 與 11/16 兩期空拍正射影像拼接，縮成約 10 m 解析度顯示。
- DEM 差分包含所有高程下降（含植被與處理方式差異造成的差距），不等同於「相對崩塌前地形的殘餘土砂量」。
- 影像與 DEM 的原始資料來源與使用授權，請於引用或再利用前自行確認。
